### 性能瓶颈分析

#### 瓶颈 1: 标签过滤 🔍

**问题**: 使用 JSON 包含查询效率低
```python
# SQLite 标签查询
stmt = stmt.where(SearchIndex.tags.contains(tag))
```

**影响**: 中等（大型数据集）

**解决方案**:
1. 使用关联表（多对多关系）
2. PostgreSQL GIN 索引
3. 标签缓存

**实施成本**: 高

#### 瓶颈 2: 全文搜索 🔍

**问题**: LIKE 查询对大文本效率低
```python
# 当前实现
stmt = stmt.where(
    or_(
        SearchIndex.title.like(f"%{query}%"),
        SearchIndex.content.like(f"%{query}%")
    )
)
```

**影响**: 低（当前性能已优秀）

**解决方案**:
1. PostgreSQL FTS (全文搜索)
2. 外部搜索引擎（Elasticsearch）
3. 搜索结果缓存

**实施成本**: 中

#### 瓶颈 3: 洞察聚合 🔍

**问题**: 大数据集的 Python 端聚合
```python
# 当前实现
for item in items:
    if item.tags:
        unique_tags.update(item.tags)
```

**影响**: 低（已限制查询数量）

**解决方案**:
1. 数据库端聚合（SQL GROUP BY）
2. 预聚合表
3. 增量更新

**实施成本**: 中
