### Features Implemented

#### 1. Insight Data Models
- **InsightExtension:**
  - claim: Insight statement (核心洞察)
  - rationale: Reasoning process (推理过程)
  - implications: List of implications (启示列表)
  - claim_hash: SHA-256 for deduplication (去重)
  - source_refs: Source item IDs (来源引用)
  - review_status: pending/approved/rejected (审核状态)
- **InsightCluster:** Temporary cluster for mining
- **Helper Functions:**
  - generate_claim_hash(): SHA-256 hash
  - normalize_claim(): Claim normalization

#### 2. Insight Miner
- **LLMClient:**
  - LLM abstraction (supports OpenAI, Anthropic, local)
  - Mock generation for Stage 5
  - Prompt template for cluster→insight conversion
- **InsightMiner:**
  - mine_from_cluster(): Generate insight from cluster
  - find_high_density_clusters(): DFS-based discovery
  - create_cluster(): Create mining cluster
  - Automatic deduplication via claim_hash

#### 3. Insight CRUD
- create_insight(): Create with deduplication check
- get_insight(): Retrieve single insight
- list_insights(): List with status filter
- update_insight_review(): Approve/reject insights
- delete_insight(): Soft delete
- get_insights_by_source(): Query by source items
- get_insight_stats(): Statistics aggregation

#### 4. API Endpoints
```
POST /insights                       - Create insight
GET  /insights                       - List insights
GET  /insights/{id}                  - Get insight
POST /insights/{id}/review           - Review insight
DELETE /insights/{id}                - Delete insight
POST /insights/mine                  - Mine from cluster
POST /insights/find-clusters         - Find clusters
GET  /insights/stats/workspace/{id}  - Statistics
GET  /insights/health                - Health check
```
