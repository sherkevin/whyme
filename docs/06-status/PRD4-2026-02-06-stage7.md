### 2. 密码哈希系统

**文件:** `security.py:22-63`

**哈希算法:** SHA-256 + 随机 salt

```python
def get_password_hash(password: str) -> str:
    # 生成 32 字符 hex salt
    salt = secrets.token_hex(16)

    # 组合 salt + 密码并哈希
    salted_password = f"{salt}{password}".encode('utf-8')
    password_hash = hashlib.sha256(salted_password).hexdigest()

    # 返回 salt$hash 格式
    return f"{salt}${password_hash}"
```

**验证流程:**
```python
def verify_password(plain_password: str, hashed_password: str) -> bool:
    # 分离 salt 和 hash
    salt, password_hash = hashed_password.split('$', 1)

    # 用相同 salt 哈希明文密码
    salted_password = f"{salt}{plain_password}".encode('utf-8')
    computed_hash = hashlib.sha256(salted_password).hexdigest()

    # 比较哈希值
    return computed_hash == password_hash
```

**安全特性:**
- ✅ 随机 salt（每次哈希不同）
- ✅ SHA-256 加密
- ✅ 不可逆（单向哈希）
- ✅ 97 字符固定长度（32 + 1 + 64）

**访问令牌创建:**
```python
def create_access_token(data: Dict[str, Any], expires_delta: Optional[timedelta] = None) -> str:
    to_encode = data.copy()

    # 设置过期时间
    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)

    to_encode.update({
        "exp": expire,
        "iat": datetime.utcnow(),
        "type": "access"
    })

    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
```

**令牌验证:**
```python
def decode_token(token: str) -> Optional[Dict[str, Any]]:
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except jwt.PyJWTError:
        return None
```

```python
def check_permission(user_permissions: list[str], required_permission: str) -> bool:
    for perm in user_permissions:
        # 精确匹配
        if perm == required_permission:
            return True

        # 通配符匹配（如 items:*）
        if ":" in perm:
            resource, action = perm.split(":")
            if action == "*" and required_permission.startswith(f"{resource}:"):
                return True

        # 全局通配符
        if perm == "*":
            return True

    return False
```

## 🎯 设计决策

### 1. 为什么选择 SHA-256 + Salt 而不是 bcrypt？

**原因:**
- ✅ 简单可靠，无依赖问题
- ✅ 性能优秀
- ✅ salt 提供足够安全性
- ✅ 易于理解和维护

**安全考虑:**
- SHA-256 是加密安全的哈希算法
- 随机 salt 防止彩虹表攻击
- 每个密码不同的 salt 确保哈希唯一

### 2. 为什么使用 JWT？

**优势:**
- ✅ 无状态认证
- ✅ 跨域支持
- ✅ 移动端友好
- ✅ 标准化（RFC 7519）

**令牌类型:**
- 访问令牌：短期（30分钟），用于 API 调用
- 刷新令牌：长期（7天），用于获取新访问令牌

### 3. 为什么使用 RBAC？

**优势:**
- ✅ 易于管理
- ✅ 权限聚合
- ✅ 灵活的继承
- ✅ 工作区范围隔离

**权限格式:**
- `resource:action` - 精确权限
- `resource:*` - 资源通配符
- `*` - 全局通配符
