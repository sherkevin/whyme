### 5-Dimensional Connection Score

```
Score = 0.40×vector + 0.20×keywords + 0.20×entities + 0.10×area + 0.10×time
```

1. **Vector Similarity (40%)** - Cosine similarity of embeddings
2. **Keyword Overlap (20%)** - Jaccard coefficient
3. **Entity Overlap (20%)** - Named entities (persons, orgs, emails)
4. **Same Area (10%)** - Boolean: same area_id
5. **Time Decay (10%)** - Exponential decay: exp(-days/30)
