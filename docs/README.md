## 📝 文档维护

### 文档规范

1. **所有文档使用 Markdown 格式**
2. **文件名使用小写和下划线**（除根目录保留的文档）
3. **更新文档时同步更新本导航页**
4. **过时文档移至 archive/ 目录**

### 新增文档

如需新增文档，请：

1. 确定文档类别（guides, reports, 或其他）
2. 在对应目录创建文档
3. 更新本导航页（docs/README.md）
4. 如果是核心文档，在根目录 README.md 添加链接
