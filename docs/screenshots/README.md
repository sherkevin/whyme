# Screenshots Directory

This directory contains UI screenshots and visual documentation.

## Screenshots

### Toolkit Management
- **mcp_edit_modal.png** - MCP server edit modal interface
- **toolkit_upload_success.png** - Successful file upload confirmation

## Usage

### View Screenshots
```bash
# Open in default image viewer
open screenshots/mcp_edit_modal.png

# Or use a specific viewer
display screenshots/*.png
```

### Add New Screenshots
```bash
# Place new screenshots in this directory
cp /path/to/screenshot.png screenshots/
```

## Guidelines

When adding screenshots:
1. Use descriptive filenames (e.g., `ui_component_name.png`)
2. Keep file sizes reasonable (< 500KB preferred)
3. Use PNG format for UI screenshots
4. Include context in filename or README

## Notes

- Screenshots are for documentation and visual reference
- Update screenshots when UI changes significantly
- Used in docs and for UI/UX discussions
